## 3. KURIKULUM LENGKAP (8 MODULES + AI)

### Module 0: Onboarding Week
* Navigasi resource kelas, instalasi tools dasar, pengenalan sistem komunikasi.

### Module 1: Introduction to Data Analytics
* **Materi:** Fundamentals of Data Analytics, peran tim data, proses bisnis, Lean Analytics, AARRR Metrics, analytical thinking.

### Module 2: Understanding Business Problems
* **Materi:** Framework struktur masalah (Issue Tree, Root Cause Analysis/RCA), metric reasoning, dashboard pattern recognition, prioritisasi hipotesis, event tracking di E-Commerce & Apps.
* **Output Project:** Problem Structuring & Analysis in Retail Context.

### Module 3: Statistics & Spreadsheet (AI-Integrated)
* **Materi:** Cleaning data, statistik deskriptif, Exploratory Data Analysis (EDA), kovariansi & korelasi, hypothesis testing, A/B testing, regresi, AI untuk Spreadsheet & Google Docs.
* **Output Project:** Evaluation & Analysis of E-Commerce Advertising Campaigns.

### Module 4: SQL (AI-Integrated)
* **Materi:** Konsep Database, ERD, BigQuery, fungsi & manipulasi data, JOINS, UNION, Subqueries, CTEs, Window Functions, Time Series, Cohort & Funnel Analysis, AI for SQL.
* **Output Project:** Retail Sales Insights and Revenue Analysis.

### Module 5: Python for Data Analysis (AI-Integrated)
* **Materi:** Dasar Python, NumPy, Pandas, Data Cleaning, Aggregation, Customer Segmentation, K-Means Clustering, Linear/Logistic Regression, Propensity Model, PandasAI.
* **Output Project:** Fraud, Profit, and Credit Risk Analysis for Bank Card Users.

### Module 6: Data Visualization
* **Materi:** Principles of Storytelling, visual exploratory, dashboard design, cohort analysis, forecasting, clustering.
* **Tools:** Tableau / PowerBI / Looker.
* **Output Project:** Expense Tracking & Budget Utilization Dashboard.

### Module 7: Data Communication
* **Materi:** Struktur presentasi data, visual storyboards, teknik mengomunikasikan insight untuk mendorong keputusan bisnis.

### Module 8: Production-Ready Analytics (NEW & High Demand)
* **Materi:** Otomasi workflow dengan Apache Airflow, konsep ETL (Extract, Transform, Load), membangun sistem pelaporan otomatis (*automated reporting*).

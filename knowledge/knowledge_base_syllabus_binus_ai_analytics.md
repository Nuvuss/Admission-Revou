# KNOWLEDGE BASE: DETAIL SILABUS APPLIED AI, ANALYTICS & AUTOMATION (BINUS x REVOU)

## 1. STRUKTUR DETAIL MODUL PEMBELAJARAN

### Module 1: Future of Work & Problem Solving
- **Materi:** Peran Data & AI dalam transformasi keputusan bisnis, analisis masalah menggunakan problem-solving framework, identifikasi root cause (5 Whys), penentuan business metrics, pemetaan data source.
- **Output/Kemampuan:** Merumuskan masalah bisnis secara terstruktur, memilih metrik relevan.
- **Tools:** Claude, Gemini.

### Module 2: Data & Business Analytics Fundamentals
- **Materi:** Konsep dasar data analytics & business analytics, jenis-jenis data, data cleaning, penyiapan AI-ready data, business analytics workflow end-to-end.
- **Output/Kemampuan:** Menyiapkan dataset berkualitas tinggi dan siap diproses oleh sistem AI.
- **Tools:** Claude, Gemini.

### Module 3: Exploratory Data Analysis & Data Visualization
- **Materi:** Teknik EDA, statistik deskriptif, visualisasi data, pembuatan data story v1.
- **Output/Kemampuan:** Mengidentifikasi pola/insight dan mengomunikasikannya secara visual & efektif.
- **Tools:** Claude, Gemini.

### Module 4: AI Foundations & Prompt Engineering
- **Materi:** Dasar Generative AI, teknik prompting advanced, AI reasoning, prinsip Responsible AI, evaluasi output.
- **Output/Kemampuan:** Menulis prompt efektif, mengoptimalkan respons AI yang konsisten dan akurat.
- **Tools:** Claude, Gemini.

### Module 5: Building Custom AI Assistants
- **Materi:** Perbedaan ChatGPT vs CustomGPT, desain & konfigurasi no-code AI chatbot, melatih AI dengan domain-specific knowledge, fine-tuning respons bisnis.
- **Output/Kemampuan:** Membangun AI Chatbot kustom berbasis domain knowledge tanpa koding.
- **Tools:** Claude, Gemini.

### Module 6: AI-Powered Analytics
- **Materi:** Analisis deskriptif, diagnostik, prediktif, dan sentiment analysis berbasis AI; pemrosesan data tak terstruktur; penyusunan AI Insights Pack.
- **Output/Kemampuan:** Menghasilkan AI Assistant v1 & AI Insights Pack untuk capstone.
- **Tools:** Claude, Gemini.

### Module 7: Data Product Management
- **Materi:** Product architecture berpusat pada pengguna, user persona, penentuan MVP, AI feature requirements, UI patterns untuk produk AI.
- **Output/Kemampuan:** Membedakan AI Product, AI Tool, dan Dashboard; merancang alur AI Product.
- **Tools:** Claude, Gemini.

### Module 8: Workflow Automation with n8n
- **Materi:** Membangun AI workflow menggunakan n8n, integrasi LLM ke otomasi, menghubungkan AI ke API tanpa koding, penerapan checkpoint *Human-in-the-loop*.
- **Output/Kemampuan:** Merancang dan mengeksekusi workflow otomatisasi berbasis n8n.
- **Tools:** n8n, Claude, Gemini.

### Module 9: AI Automation & API Integration
- **Materi:** Integrasi AI dengan pihak ketiga (Google Sheets, Slack, Email, CRM), otomasi end-to-end (Trigger → Data → AI Step → Output), testing skenario edge cases & failure.
- **Output/Kemampuan:** Terampil mengintegrasikan AI dengan ekosistem aplikasi produktivitas bisnis.
- **Tools:** n8n, Google Sheets, Slack, Claude, Gemini.

### Module 10: Agentic AI & Multi-Agent Systems
- **Materi:** Konsep otonomitas AI Agent (goal-based behavior, decision making, tool usage), perbedaannya dengan chatbot/otomasi biasa, arsitektur multi-agent, penanganan risiko agentic.
- **Output/Kemampuan:** Membangun dan menguji sistem multi-agent terspesialisasi di n8n untuk alur kerja kompleks.
- **Tools:** n8n.

### Module 11: Claude Code for Automation & Tool Selection
- **Materi:** Penggunaan Claude Code untuk pemrosesan data (membaca, membersihkan, output otomatis), komparasi n8n vs Claude Code, penentuan tool stack untuk Capstone.
- **Output/Kemampuan:** Mampu membuat otomasi berbasis data menggunakan Claude Code dan memilih tool yang tepat.
- **Tools:** Claude Code.

## 2. METODE CAPSTONE PROJECT
Selama fase Capstone, peserta akan melewati siklus:
1. **Product Brief:** Definisi problem, user persona, dan AI solution.
2. **Build Sprint:** Pembangunan AI Product menggunakan n8n / Claude Code / Custom Assistants.
3. **Mentorship & Review:** Feedback berkala dari praktisi dan instruktur.
4. **Final Presentation:** Pitching produk AI di depan panel juri.
5. **Graduation & Responsible AI Pledge:** Penandatanganan komitmen etika AI.

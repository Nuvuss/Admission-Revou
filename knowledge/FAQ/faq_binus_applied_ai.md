#### Kalo dikantor gabisa pake Claude, cuma pake Copilot gimana?

```text
Hai, menurutku tetap layak diikuti. Skill inti kerja bareng AI itu sama di semua tools, karena Claude dan Copilot sama-sama berbasis large language model. Cara ngasih konteks, nulis instruksi yang jelas, kasih contoh output yang diinginkan, mecah kerjaan besar jadi langkah kecil, sama ngecek hasilnya biar nggak kena halusinasi, itu semua kepake di Copilot juga.

Fitur yang dipelajari di Claude juga kebanyakan ada padanannya di Copilot:
Projects di Claude (kumpulin dokumen dan instruksi per topik) mirip Notebooks atau agent custom di Copilot
	•	Artifacts mirip Copilot Pages
	•	Bikin workflow atau agent sendiri bisa dipraktekin di Copilot Studio
	•	Claude di Excel dan PowerPoint mirip Copilot di Excel dan PowerPoint

Copilot malah punya kelebihan buat kerjaan kantor, karena dia bisa baca email, Teams, sama file SharePoint perusahaan langsung. Jadi kalau dia udah jago bikin prompt dan struktur kerja dari program ini, hasilnya bisa lebih kerasa di Copilot karena datanya udah nyambung.

Satu lagi, Microsoft 365 Copilot sekarang udah bisa pake model Claude di beberapa fitur, misalnya Researcher dan Copilot Studio. Tapi ini harus diaktifin admin IT, jadi coba ditanyain ke tim IT kantornya.
```

#### Apakah ada materi Agentic AI & Multi-Agent Systems?

```text
Ada! Di program BINUS Applied AI, Analytics & Automation, materi Agentic AI dipelajari secara hands-on (No-Code/Low-Code) pada *Week 7–8 (Module 10: Agentic AI & Multi-Agent Systems)* dan *Week 9*:
- Konsep otonomitas AI Agent (goal-based behavior, decision making, tool usage) dan perbedaannya dengan chatbot atau otomasi biasa
- Arsitektur & orkestrasi sistem multi-agent (*Multi-Agent Systems*) serta penanganan risiko agentic
- Praktik membangun dan menguji sistem multi-agent terspesialisasi di *n8n* untuk alur kerja kompleks
- Week 9: Fondasi *Claude Code* untuk otomasi berbasis data, integrasi agentic lanjutan, dan seleksi tool stack untuk Capstone
```

#### Tools apa saja yang dipelajari di BINUS Applied AI?

```text
Program ini 100% No-Code/Low-Code dan menggunakan ekosistem tools berikut:
- *AI Assistants & LLM:* Claude dan Gemini (prompt engineering, Custom AI Assistants, AI-powered analytics)
- *Workflow Automation & Multi-Agent:* n8n (termasuk integrasi API pihak ketiga ke Google Sheets, Slack, Email, dan CRM dengan checkpoint Human-in-the-loop)
- *Data Automation:* Claude Code (Week 9 / Module 11) untuk membaca, membersihkan, dan mengotomatisasi pemrosesan data
```

#### Bagaimana struktur kurikulum & metode Capstone Project-nya?

```text
Program berdurasi 12 minggu dengan 11 modul terstruktur: Problem Solving & Data Fundamentals, EDA & Visualization, Prompt Engineering, Custom AI Assistants, AI-Powered Analytics, Data Product Management, Workflow Automation (n8n), API Integration, Agentic AI & Multi-Agent Systems, hingga Claude Code for Automation.

Untuk Capstone Project, peserta melewati 5 tahap:
1. Product Brief (definisi problem, user persona, dan AI solution)
2. Build Sprint (pembangunan AI Product menggunakan n8n / Claude Code / Custom Assistants)
3. Mentorship & Review berkala dari praktisi dan instruktur
4. Final Presentation (pitching produk AI di depan panel juri)
5. Graduation & Responsible AI Pledge
```

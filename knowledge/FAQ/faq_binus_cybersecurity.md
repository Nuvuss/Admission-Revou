### BINUS: Applied Cybersecurity with AI

#### Tentang Program

##### Apakah program ini mengajarkan ethical hacking / offensive security?

```text
*Bukan*. Ini adalah program pertahanan (*Defensive Cybersecurity / Blue Team*). Peserta belajar cara mendeteksi, menginvestigasi, dan merespons ancaman siber. Pola pikir penyerang dipelajari semata-mata untuk mengantisipasi dan memperkuat benteng pertahanan sistem.
```

##### Berapa lama programnya & bagaimana jadwal belajarnya?

```text
Durasi program *12 minggu* dengan format *Hybrid*:
- *Live Online Sessions:* Senin, Selasa & Kamis (Lecture + Applied Workshop) pukul 19.30 – 21.30 WIB
- *On-Campus Sessions:* 5 sesi tatap muka di Kampus BINUS University (Kemanggisan) untuk AWS Labs onsite, simulasi pertahanan, dan wisuda (tersedia juga opsi full online termasuk akses live AWS Labs via cloud)
- Komponen: 24 Live Lectures, 10 Hands-on Workshops, 3 Live AWS Labs, 5 Portofolio Artifacts, dan 1 AI-Assisted Capstone Project
```

##### 3 Live AWS Labs-nya ngapain aja?

```text
Semua lab dijalankan di lingkungan live cloud infrastructure AWS resmi:
1. *Lab 01 – Threat Triage Simulation:* Menyelidiki antrean alert realistis, memisahkan sinyal serangan asli dari noise, dan memprioritaskan penanganan insiden seperti SOC Analyst
2. *Lab 02 – Network Security Simulation:* Mengeksplorasi infrastruktur cloud AWS untuk memetakan jalur ancaman jaringan, menganalisis titik rentan, dan memperkuat konfigurasi pertahanan
3. *Lab 03 – Autonomous AI Assessment:* Mengonfigurasi, men-deploy, dan mengevaluasi kinerja AI-powered security agent dalam operasional keamanan modern
```

#### Prasyarat

##### Apakah saya bisa mengikuti program ini jika belum pernah belajar cybersecurity?

```text
Ya, bisa! Program ini tidak mensyaratkan pengalaman cybersecurity sebelumnya. Namun, pendaftar wajib memiliki dasar logika IT, memahami konsep dasar koding/scripting, dan mampu membaca dokumentasi teknis berbahasa Inggris.
```

#### Kurikulum & Capstone

##### Capstone Project-nya seperti apa & apa saja deliverables portofolionya?

```text
Capstone berupa *AI-Assisted Security Tooling & Automation* — peserta membangun tool keamanan siber berbasis alur kerja modern untuk menjawab tantangan operasional nyata. Ada 5 deliverables portofolio wajib:
1. Working Security Tool (berfungsi aktif, bukan sekadar rancangan)
2. Architecture & Workflow Walkthrough
3. Functional Testing & Execution Evidence
4. Security & Operational Rationale
5. AI Use Log & Calibration (catatan validasi output AI & human judgment)
```

#### Konten AI

##### Seberapa banyak unsur AI yang diajarkan?

```text
AI hadir sejak minggu pertama sebagai asisten kerja analis: digunakan untuk memetakan alert, mempercepat triage log, menyusun draf laporan teknis insiden, menjalankan evaluasi kerentanan, hingga mengonfigurasi autonomous AI security agent.
```

##### Apakah belajar Agentic AI / Autonomous AI Security Agent?

```text
Ya, pada *Week 10 (Autonomous AI in Security)* dan *Lab 03 AWS (Autonomous AI Assessment)*, peserta langsung mempraktikkan konfigurasi, deployment, dan evaluasi efektivitas *Autonomous AI Security Agent* dalam operasional keamanan modern (Blue Team).
```

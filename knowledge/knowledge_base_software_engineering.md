## 3. KURIKULUM & MATERI PER PHASE

### Phase 1: Algorithm & Programming
* **Fokus:** Fondasi logika pemrograman, alur berpikir program, pemrosesan data, dan efisiensi algoritma sebelum penulisan kode kompleks.
* **Materi:**
  * Logic Foundations & Web Application Architecture
  * Algorithms & System Logic
* **Aktivitas & Output:** Flowchart, pseudocode, modular reusable functions, algoritma dasar, GitHub version control.
* **Tools:** GitHub, Lucidchart, Miro.

### Phase 2: Backend Development (AI-Powered)
* **Fokus:** Pembangunan server-side application, pengelolaan database PostgreSQL, dan integrasi AI pada backend workflow.
* **Materi:**
  * Software Engineer Toolkit
  * Database with PostgreSQL
  * Python Core Fundamentals
  * Flask Development Framework
  * API Development
  * Quality Assurance & Deployment
  * AI for Backend Development
* **Tools:** Postman, PostgreSQL, Flask, HackerRank.

### Phase 3: Frontend Development (AI-Powered++)
* **Fokus:** Pembangunan User Interface (UI) modern, responsif, type-safe, dan terintegrasi dengan API Backend.
* **Materi:**
  * HTML, CSS, JavaScript Basic
  * TypeScript & Tailwind CSS
  * React Components dengan Next.js Environment
  * Next.js App Router & API Integration
  * Forms, Authentication, & Complete Backend Integration
  * Quality Assurance & Deployment (E2E testing dengan Playwright)
* **Tools:** Next.js, TypeScript, Tailwind CSS, Playwright, HackerRank.

### Phase 4: AI-Driven Development (100% AI-Powered)
* **Fokus:** Integrasi penuh AI ke seluruh Software Development Lifecycle (SDLC) untuk meningkatkan produktivitas hingga 10x.
* **Materi:**
  * AI Development Life Cycle & Requirements Engineering
  * Steering Guidelines & Code Generation dengan Kiro
  * Implementation, Testing, & Production Deployment
* **Tools:** Kiro AI.
